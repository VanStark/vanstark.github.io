m4-offsite-backup

A personal, single-user encrypted offsite backup client.

What this application is

m4-offsite-backup is a privately operated command-line tool, built on the open-source rclone project. It is used by exactly one person — its owner — to copy already-encrypted backup archives from the owner's own local storage to the owner's own Google Drive. It is not distributed, not offered to the public, and has no other users.

What Google user data it accesses

The application requests a single OAuth scope: https://www.googleapis.com/auth/drive.file. Under that scope Google grants access only to files that this application itself creates. The application cannot see, read, modify, or delete any other file in the account: not the owner's documents, photos, mail, or any file created by another application.

What it does with that data

  • Uploads encrypted archive files (identified by file name and SHA-256 checksum) into one folder that the application creates in the owner's Drive.
  • Lists that same folder to apply a retention rule, and deletes its own older archives from that folder, permanently (files are not sent to the Drive trash).
  • Downloads one of its own archives back to local storage to verify the checksum after upload.

That is the entire data flow. Nothing else is read, collected, transmitted, or transferred to any third party. The archives are encrypted locally with age (or, for disk images, with AES-256) before they are uploaded, so the stored objects are ciphertext.
